    Run the two recovery experiments
    1. Disconnect, add three events, reconnect. Only the three missing events are replayed.
    2. Disconnect, add 25 events, reconnect. History has expired, so one snapshot replaces the local state.
    3. Restart the server. Its stream identifier changes and the client accepts a new snapshot.
    A local, single-process teaching implementation. Memory is bounded; state resets when the server restarts. Writes are not retried automatically.
